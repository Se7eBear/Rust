A Norma Rustacean
Todo projeto deve seguir estas regras. Na avaliação, qualquer violação resulta em reprovação automática — assim como a Norminette na 42 original.
Regras obrigatórias
  • Compilar sem warnings: cargo build deve passar limpo
  • Sem unwrap() em código de produção — use match, if let ou ?
  • Funções com no máximo 30 linhas
  • Todos os erros devem ser tratados explicitamente
  • Sem código morto ou variáveis não utilizadas
  • Rodar cargo clippy sem warnings antes de entregar
  • Cada projeto criado com cargo new — não manualmente
Estrutura de Workspace (Rank 01 em diante)
# Cargo.toml da raiz do workspace:
[workspace]
members = [
    "ft_strlen",
    "ft_atoi",
    "fizzbuzz_pro",
]
resolver = "2"

# Comandos do dia a dia:
cargo run -p ft_strlen        # rodar um projeto
cargo test -p fizzbuzz_pro    # testar um projeto
cargo check -p ft_atoi        # checar sem compilar
cargo clippy -p ft_strlen     # linter
Tipos que fazem Copy vs Move
// Tipos Copy (primitivos) — cópia automática:
let a: i32 = 10;
let b = a;   // cópia — a ainda é válido

// Tipos Move (heap) — transferência de posse:
let s1 = String::from("hello");
let s2 = s1; // s1 MOVIDO — s1 inválido agora!

// Tipos Copy: i8..i128, u8..u128, f32, f64, bool, char, tuplas de Copy
// Tipos Move: String, Vec, HashMap, Box, qualquer struct sem #[derive(Copy)]

ft_args
Leia e imprima argumentos da linha de comando
100 XP★☆☆☆▾
Objetivo
Programa que recebe N argumentos e imprime cada um em uma linha, numerado. Se nenhum argumento, imprime No arguments provided.
Exemplo de uso
$ cargo run -- hello world rust
1: hello
2: world
3: rust

$ cargo run
No arguments provided.
Requisitos obrigatórios
  • Usar std::env::args()
  • Pular o primeiro argumento (nome do binário) com .skip(1)
  • Numerar cada argumento a partir de 1
  • Tratar o caso sem argumentos com mensagem exata
Solução correta
use std::env;

fn main()
{
    let args: Vec<String> = env::args().collect();

    if args.len() == 1
    {
        println!("No arguments provided.");
        return;
    }

    for (i, arg) in args.iter().skip(1).enumerate()
    {
        println!("{}: {}", i + 1, arg);
    }
}
Conceitos
std::enviteratorsenumerateskipVec

Referência rápida — Macros em Rust
Visão geral dos dois tipos de macro e os subjects de cada rank.
Tipo 1 — macro_rules! (declarativas)
Funcionam como um match em cima de padrões de tokens. Você define padrões de entrada e o que gerar para cada um. Rodam em compile time.
macro_rules! meu_vec {
    () => { Vec::new() };
    ($($x:expr),+) => {{
        let mut v = Vec::new();
        $(v.push($x);)+
        v
    }};
}
// Designadores: expr, ident, ty, literal, tt, stmt, pat, path
// Repetição: $(...),*  (0+)  |  $(...),+  (1+)
Tipo 2 — Macros procedurais
Manipulam a AST (árvore sintática) do Rust. Vivem em um crate separado com proc-macro = true. Três subtipos:
// 1. Derive macro:
#[derive(MinhaDerive)]
struct Foo { x: i32 }

// 2. Attribute macro:
#[minha_macro(arg)]
fn handler() {}

// 3. Function-like macro (proc):
minha_macro!(...)

// Crates necessários para implementar:
// syn = "2"   → parse da AST
// quote = "1" → gerar tokens Rust
Macros built-in mais usadas
println!    // stdout com newline
eprintln!   // stderr com newline
format!     // retorna String formatada
vec!        // cria Vec com valores
assert!     // panic se falso
assert_eq!  // panic se a != b (mostra valores)
panic!      // para o programa imediatamente
todo!       // panic com "not yet implemented"
unreachable! // panic se código impossível rodar
dbg!        // imprime nome e valor no stderr
file!       // &str com caminho do arquivo atual
line!       // u32 com número da linha atual
stringify!  // converte tokens em &str literal
include_str! // inclui arquivo como &str em compile time
cfg!        // condição de compilação
